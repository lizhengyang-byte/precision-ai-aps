## 三、共性空白

1. **人员技能没有进入排产决策**：绝大多数系统把“人”只当作报工主体，不建模技能等级与工序准入，导致计划下发后“没人能干”。
2. **计划不可解释**：要么黑箱求解，要么纯手工拖拽，计划员无法回答“为什么这单排在后面”。
3. **变更靠全表重排**：设备故障、人员请假、插单发生时，缺少“冻结已开工 + 局部重排 + 影响对比”的闭环，只能人工改表。
4. **中文自然语言入口缺失**：现场变化靠电话/微信群传递，没有直接变成调度指令的通道。

## 四、本项目定位

不做“又一个全功能 MES”，而做**精密加工车间专用的 AI 排产与进度管控内核**：

- 以 CP-SAT 做有限产能排产，显式建模**设备精度等级 + 人员技能矩阵 + 班次日历 + 工序先后**；
- 用可解释规则做**策略推荐**与**交付风险雷达**，每条结论都能回溯到具体指标；
- 用**版本化 + diff** 支撑“滚动重排”，已开工工序冻结，变更影响逐条列出；
- 用中文 NLU 把“三号机故障停 4 小时”“PO 加急”直接变成重排事件。

上述四点正是开源项目普遍缺失、而精密加工（多品种小批量、精度敏感、设备昂贵）最需要的部分。
