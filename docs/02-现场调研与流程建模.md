# 02 · 现场调研与生产管理流程建模

## 一、调研对象与方式

选取一家典型精密加工车间（多品种小批量、以 CNC 铣/车/磨为主）做流程写实：跟班观察 3 个班次、访谈计划员/班组长/操作工共 9 人、导出近 3 个月工单与报工记录，形成“现状流程 + 约束清单 + 数据字典”。

## 二、现状流程（As-Is）

1. **接单与评审**：销售接单 → 工艺评审（公差、材料、表面处理）→ 计划员口头承诺交期。
2. **工艺准备**：工艺员编工艺路线（粗加工 → 精加工 → 热处理 → 磨削 → 三坐标检测），估算标准工时。
3. **排产**：计划员用 Excel 维护“设备-日期”表，按经验把工序填进格子；紧急单靠打电话插队。
4. **下发与执行**：打印工单卡随件流动，操作工自检、首件送检。
5. **报工与跟单**：班末纸质报工，次日录入 Excel；进度靠计划员巡车间口头确认。
6. **异常处理**：设备故障/人员请假 → 班组长临时改派 → 计划员手工重排受影响订单。

## 三、关键痛点（To-Be 要解决的）

| 痛点 | 现场表现 | 后果 |
| --- | --- | --- |
| 排产靠经验 | 同一批设备，不同计划员排出的交期差 2~5 天 | 交期承诺不可信 |
| 技能不匹配 | 高精度磨削排给了 L2 操作工，首件超差返工 | 质量损失、设备空转 |
| 变更成本高 | 一次插单要手工改 20+ 行，常常漏改 | 计划与实际两张皮 |
| 进度不透明 | 报工滞后 1 天，客户催单才知道拖期 | 交付风险发现太晚 |
| 瓶颈无量化 | 不知道哪台设备是真瓶颈 | 投资与加班决策拍脑袋 |

## 四、建模要素（数据字典）

- **设备（WorkCenter）**：编码、名称、设备类型（mill/lathe/boring/grind/edm/inspect/heat）、精度等级 1~3、效率系数、状态（可用/维保/停机）。
- **人员（Operator）**：编码、姓名、技能等级 L1~L5、技能矩阵 `{工序类型: 等级}`、班次。
- **产品与工艺（Product / Routing）**：产品族（决定换型损失）、材料、公差（μm）、工序序号、工序类型、标准工时、装夹时间、最低人员等级、所需设备类型、最低设备精度。
- **订单（Order）**：数量、交期、优先级 1~3（普通/较高/加急）、客户、下达时间。
- **日历（ShopCalendar）**：班次 08:00–20:00，周日休息；工序不跨班，跨班自动顺延到下一可用窗口。
- **事件（EventLog）**：设备故障、人员缺勤、插单、批量变更，带起止时间与影响范围。

## 五、约束清单（硬约束 / 软约束）

硬约束：

1. 同一设备同一时刻只能加工一道工序；
2. 同一人员同一时刻只能守一台设备；
3. 工序必须按工艺路线先后执行，前道完工才能开后道；
4. 人员技能等级 ≥ 工序最低要求，设备精度 ≥ 工序最低精度，设备类型匹配；
5. 工序只能落在班次窗口内，不跨班；
6. 已开工工序冻结，不得移动；故障/缺勤区间内设备与人员不可用。

软约束（目标函数体现）：

1. 加权拖期最小（加急单权重高）；
2. 完工跨度尽量短；
3. 在制停留时间尽量短；
4. 同产品族连续投产，减少换型。

## 六、现状量化基线

调研月内平均：在制订单 12~18 张、设备综合利用率 62%、按期交付率 78%、计划变更每周 4.6 次、单次手工重排耗时 40~90 分钟。这组数字作为系统上线后的对比基线。
